# Требования к функции

Используй для проработки требований, а не как обязательный этап любой правки.

1. Прочитай AGENTS.md и релевантный код. Раздели текущее поведение и желаемое.
2. Опиши пользователя, проблему, основной сценарий, состояния ошибки и измеримый результат.
3. Уточняй только вопросы, меняющие объём или контракт. Не придумывай согласованные требования; допущения помечай.
4. Сохраняй документ в `docs/prd/<slug>.md` целевого репозитория, если запрос предполагает документ. Для сквозной задачи выбери один владеющий репозиторий и сошлись на контракт из второго.
5. Не начинай реализацию, если запрошены только требования. Если реализация уже разрешена, не добавляй новый барьер согласования.

Структура документа: проблема; сценарии; входит/не входит; критерии готовности; ошибки/пограничные случаи; открытые вопросы. Почта, роли, уведомления и другие дополнительные возможности не появляются без запроса.
