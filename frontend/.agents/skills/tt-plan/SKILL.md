# Исследование и план

1. Прочитай AGENTS.md, задачу и существующие требования. Через rg найди точки входа, потребителей и тесты. Не сканируй зависимости и generated-код без причины.
2. Для спорного API сначала посмотри установленную версию и локальные типы/документацию; при необходимости используй официальные источники. Зафиксируй ссылки и отличай факт от предположения.
3. Определи минимальное решение и затрагиваемые контракты: маршруты, DTO, cookie, модель БД, состояния UI. Не копируй схему другого проекта без проверки.
4. Разбей работу на законченные шаги: файлы/ответственность, результат, проверка. Учти миграцию данных и совместимость клиента с API.
5. Для большого плана используй `docs/plans/<slug>.md` внутри целевого репозитория: цель, исходные факты, решение, шаги с чекбоксами, проверки, риски и открытые вопросы.
6. Если просят только план — верни план. Если уже просят выполнить работу — продолжай реализацию, не требуя повторного разрешения.

Не заявляй, что endpoint работает, только потому что существует controller: проследи его подключение. Для frontend различай корневой Next app и FSD src/pages. Команды бери из локального AGENTS.md и package.json.
