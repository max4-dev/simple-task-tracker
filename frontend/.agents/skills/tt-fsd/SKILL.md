# FSD проекта

Прочитай frontend AGENTS.md (или AGENTS.md в cwd frontend) и соответствующий раздел локальной документации Next.

- Корневой app — Next App Router; src/pages — композиция страниц. Не создавай второй роутер в src/app и не удаляй pages/README.md без проверки назначения.
- Начинай со страницы для локального сценария. Выделяй features для повторно используемого пользовательского действия, entities для общей доменной модели, shared для кода без знания бизнес-домена.
- Зависимости направлены вниз: app → pages → widgets → features → entities → shared. Не создавай пустые слои и не связывай независимые слайсы одного уровня.
- UI-примитив: src/shared/ui/<name>/<name>.tsx. Единственный публичный barrel UI-кита — src/shared/ui/index.ts. Не создавай index.ts в папке компонента.
- Потребители импортируют из @/shared/ui; внутри кита разрешены прямые относительные импорты для исключения barrel-циклов.
- Не переноси auth/task API в shared/ui. Общий транспорт может жить в shared/api; доменные операции принадлежат соответствующему сценарию/модели.
- Изоляция server/client важнее удобства общего экспорта. Проверяй, что клиентский импорт не захватывает серверный модуль или секрет.
- Не навязывай barrel-файлы другим слоям при отсутствии такого соглашения.

После изменения проверь потребителей через rg, TypeScript и сборку по AGENTS.md. Укажи основание для нового слоя/слайса, если он появился.
