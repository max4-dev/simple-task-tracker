# Реализация функции

1. Прочитай AGENTS.md и доступные требования. Проверь git status и diff, зафиксируй границы задачи; учитывай существующие untracked-файлы.
2. Найди фактический путь выполнения. Для неоднозначного изменения контракта используй tt-plan; простой баг не требует отдельного PRD.
3. Внеси минимальные законченные изменения по архитектуре проекта. При сквозной задаче согласуй backend DTO/статусы/cookie и frontend состояния.
4. Для ошибки, сложной логики, доступа или миграции добавь подходящую регрессионную проверку; не пиши тесты, лишь повторяющие реализацию. Не подменяй проверку БД моками, если меняется SQL/миграция.
5. Выполни подходящие команды из AGENTS.md. UI проверь в браузере доступным инструментом. Секреты, cookie и пароли не попадают в отчёт или скриншоты.
6. Посмотри итоговый diff и новые файлы. Исправь выявленные проблемы внутри задачи; независимые проблемы опиши отдельно.
7. Верни результат, завершённые проверки и ограничения. Не выдавай наличие кода за рабочую интеграцию. Commit/push/PR и отправка сообщений требуют соответствующего запроса пользователя.

При сбое окружения продолжай независимую работу. Не маскируй провал флагами пропуска, ослаблением тестов или сменой зависимостей вне задачи.
