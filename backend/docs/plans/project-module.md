# Модуль проектов

Правила: создать проект может любой участник организации; создатель автоматически
добавляется в проект с живым наследованием своей роли. Обычный участник организации
не видит чужие проекты. Owner организации видит все проекты. Роли визуальные.

Удаление согласовано: только owner организации, с подтверждением паролем.
Архивирование/восстановление доступно участникам; архив читается, изменения блокируются.
Проектные участники выбираются из существующих участников организации.
Начальные колонки: Backlog, Todo, In progress, Review, Done.
Префикс замораживается после первого выданного номера задачи.

- [x] DTO, Swagger и подключение ProjectModule.
- [x] Создание, списки, настройки, архивирование/восстановление, удаление.
- [x] Участники и живое наследование/переопределение визуальной роли.
- [x] Статусы и теги; безопасное удаление используемых статусов.
- [x] Общая блокировка организация → проект перед проверкой прав и изменением.
- [x] Тесты: валидация, реальный HTTP/PostgreSQL/Redis, изоляция, гонки, каскады.
- [x] lint, typecheck, unit/e2e, build, Docker healthcheck.

Результат: 117 unit-тестов, 13 HTTP e2e-тестов и test:domain с временными
PostgreSQL/Redis прошли. Локальный образ API пересобран, контейнер healthy;
readiness, новые маршруты Swagger и запрет анонимного доступа проверены.
Контракт описан в [../project-module.md](../project-module.md).

Миграция не ожидается: используются существующие модели. Задачи, API доски с
карточками, GitHub-интеграция и репозитории остаются для следующих модулей.
