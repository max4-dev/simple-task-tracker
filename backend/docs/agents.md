# Агенты проекта

Это приложение единого монорепозитория task-tracker. Его настройки: `AGENTS.md`, `.agents/skills/`, `.codex/agents/`; общие инструкции и ссылки на навыки находятся в корне монорепозитория. После изменения настроек открой новую сессию.

## Использование

- `$tt-prd` — требования и критерии готовности.
- `$tt-plan` — исследование существующего кода и план.
- `$tt-implement` — реализация задачи с проверкой.
- `$tt-refactor` — изменение структуры с сохранением поведения.
- `$tt-feature-review` — явно запрошенная реализация с независимым ревью.

Для небольшой задачи достаточно обычного запроса. Навыки не требуют обязательного согласования каждого этапа, не публикуют issues/PR и не делают коммиты автоматически. Незакоммиченные файлы сохраняются.

## Роли и ограничения

`scout` исследует код; `reviewer` проверяет изменения и возвращает подтверждённые проблемы. Они не изменяют файлы по инструкции, но наследуют sandbox и разрешения родительской сессии. Модель/effort не фиксированы. Делегирование запускается по запросу либо явному `$tt-feature-review`; неявный вызов этого навыка отключён. Если клиент не поддерживает субагентов, он должен сообщить, что независимого ревью не было.

Роли оформлены как standalone TOML в .codex/agents и не требуют config.toml. См. [документацию субагентов](https://learn.chatgpt.com/docs/agent-configuration/subagents) и [навыков](https://learn.chatgpt.com/docs/build-skills). Общие навыки пока есть в обоих приложениях; для общего изменения процесса обновляй обе копии. Git хранит оба приложения и корневые настройки вместе.

## Проверка

`python3 backend/scripts/check-agent-setup.py` из корня монорепозитория (Python 3.11+) проверяет форматы, метаданные и ссылки без сети и запуска приложения. Команды проверки приложения перечислены в AGENTS.md и должны соответствовать package.json.

Дополнительный навык: `$tt-backend` — NestJS API, Prisma, Redis, JWT/HttpOnly cookie, Argon2, конфигурация и TIME.
